#Linearcalc
CLI Linear Equation Solver in C
​An interactive command-line application designed to solve systems of linear equations with two or three unknowns using Cramer's Rule.
​Key Features:
​2D & 3D Matrix Solving: Calculates unique solutions for systems of 2 or 3 unknown variables.
​Determinant Boundary Handling: Identifies mathematical edge cases, including systems with no solution or infinitely many solutions (D = 0).
​Interactive Terminal UI: Built with ANSI escape codes for styled text and a continuous while loop interface for back-to-back calculations.
